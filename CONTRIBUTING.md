# Hissa qoʻshish / Contributing

Rahmat! Bu loyiha hamjamiyat yordamida oʻsadi.

## Qanday yordam berish mumkin

- **Yangi shablon** — `src/templates/` ichida yangi fayl yarating, `zod` sxemasi va `defaults` qoʻshing, keyin `src/Root.tsx` da roʻyxatdan oʻtkazing.
- **Rang mavzusi** — `src/theme.ts` dagi `THEMES` ga qoʻshing va `themeSchema` ni yangilang.
- **Xatolar** — Issues boʻlimida yozing: qaysi shablon, qanday matn, nima notoʻgʻri koʻrindi (skrinshot bilan).
- **Hujjatlar** — README ni yaxshilash, inglizcha yoki ruscha tarjima.

## Qoidalar

1. Fork qiling, alohida branch oching.
2. `npm run typecheck` xatosiz oʻtishi kerak.
3. Studioʻda shablon toʻgʻri koʻrinishini tekshiring (`npm run dev`).
4. PR tavsifida nima oʻzgarganini va iloji boʻlsa, skrinshot qoʻshing.

Standart matnlarda haqiqiy shaxslar, soxta yangiliklar yoki tasdiqlanmagan huquqiy daʼvolardan foydalanmang — faqat namunaviy (placeholder) matn.

---

*English: fork, branch, keep `npm run typecheck` green, check the template in Studio, open a PR with a screenshot. Use placeholder text only in default props.*
